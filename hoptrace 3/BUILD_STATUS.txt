To build in Android Studio:

2. Open this project folder and allow Gradle to download its dependencies.
3. Run: ./gradlew assembleDebug
4. APK output: app/build/outputs/apk/debug/app-debug.apk

The app requires the user's own IPinfo City-level/Legacy Free token for city-level
geolocation. The token is entered inside the app and is not embedded in this archive.
