# HopTrace Android 快速开始

## 项目定位

HopTrace 是原生 Android 网络诊断 App，使用 ICMP Echo + TTL/Hop Limit 逐跳探测，支持 IPv4、IPv6 与 Auto；将公网路由跳点交给 IPinfo City-level API 查询城市级估算坐标，并使用 MapLibre Native + OpenFreeMap 绘制地图和跳点连线。

## Android 版本

- `minSdk 26`：Android 8.0+
- `compileSdk 37` / `targetSdk 37`：面向 Android 17，同时覆盖 Android 15、16
- Java 17、NDK `28.2.13676358`、CMake `3.22.1`

## 地理位置 API

应用使用 `https://ipinfo.io/{IP}/json?token=...` 的 IPinfo City-level / Legacy Free 接口，以取得 `city`、`region`、`country`、`org` 和 `loc` 经纬度。

首次运行后，点击右上角 **IPinfo API**，粘贴你自己的 Token。应用不会内置共享 Token。每个公网 IP 的结果本地缓存 7 天；同一个 IP 在多跳中重复出现时会复用同一份查询结果。私网、回环、链路本地、组播及文档保留地址不会发送到 IPinfo。

注意：IPinfo Lite 虽然不限请求次数，但免费数据主要是国家/ASN 维度，没有城市坐标；不能满足本 App 的城市级地图需求。IPinfo 官方资料当前列出的 Legacy Free 城市级 API 配额为每月 50,000 次。服务计划可能变更，请以账户 Dashboard 为准。

## 地图

MapLibre Native OpenGL SDK 读取 OpenFreeMap Liberty 样式。公共地图服务当前公布无需 API Key、无地图浏览/请求次数限制；它是公共服务，不等同于有 SLA 的商业地图 API。

## 编译 APK

安装 Android Studio，并通过 SDK Manager 安装：

- Android SDK Platform 37
- Android SDK Build Tools 36.0.0
- Android NDK 28.2.13676358
- CMake 3.22.1

在项目根目录执行：

```bash
./gradlew assembleDebug
```

APK 路径：

```text
app/build/outputs/apk/debug/app-debug.apk
```

首次构建需要联网下载 Gradle、Android Gradle Plugin、AndroidX、Material Components 和 MapLibre 依赖。

## ICMP 的限制

底层采用 Linux ping socket（`SOCK_DGRAM` + `IP_RECVERR` / `IPV6_RECVERR`）和 error queue，不请求 Root 权限。但不同厂商系统内核可能禁用普通应用的 ping socket，运营商/防火墙也可能过滤 ICMP；因此不能保证每一台 ROM 都可用。Traceroute 中的 `*` 超时也可能是路由器不回应或限速，不代表链路一定中断。

## 位置精度说明

地图显示的是 IP 注册信息/商业数据库估算的城市或网络区域中心点，不是路由器的 GPS 坐标，也不保证每跳位置都准确。有些骨干网、Anycast、VPN、运营商 NAT 或云网络 IP 可能显示为运营商登记地，与设备实际所在地相差很远。

## 使用 GitHub Actions 在线编译 APK（无需本机安装 Android Studio）

项目已附带自动构建工作流：`.github/workflows/build-apk.yml`。

1. 在 GitHub 创建一个新仓库，建议选择 **Private**。
2. 解压本项目 ZIP，进入里面的 `hoptrace` 文件夹。
3. 将 `hoptrace` 文件夹里的**所有内容**上传到 GitHub 仓库根目录。上传完成后，仓库根目录应直接看到 `build.gradle`、`settings.gradle`、`app/` 和 `.github/`，不要多套一层 `hoptrace/` 文件夹。
4. 打开仓库的 **Actions** 页面，进入 **Build HopTrace APK** 工作流。
5. 点击 **Run workflow**，选择 `main` 分支，再点击确认运行。
6. 等待运行结束。绿色勾号表示构建流程成功；在该次运行页面底部的 **Artifacts** 区域下载 `HopTrace-debug-apk`。
7. 解压下载的 Artifact，得到 `app-debug.apk`，传到 Android 手机安装。

工作流会在 GitHub 云端安装 JDK 17、Android API 37、Build Tools 36.0.0、NDK 28.2.13676358、CMake 3.22.1 和 Gradle 9.6.0，再运行 `assembleDebug`。

注意：本源码包没有 `gradle-wrapper.jar`，所以工作流下载固定版本的 Gradle 并直接执行 `gradle assembleDebug`，不要改成 `./gradlew assembleDebug`。首次构建需要云端下载 Android SDK 和 Maven 依赖。该工作流输出的是可供测试安装的 **debug APK**，不是已配置发布签名的正式 release 包。
